AI Healthcare Bot System

Describe your symptoms and get basic precautions instantly, then find doctors, clinics and hospitals near you. Built for people who cannot easily reach healthcare, especially in rural areas.

Hello! Tell me your symptoms, for example "I have fever".

How the system works

User module

  • Register, login and manage profile
  • Change password
  • Chat with the bot about health queries
  • View nearby doctors, clinics and hospitals

Admin module

  • Login directly
  • Manage questions and answers
  • Train the model
  • View registered users

Technology

  • HTML, CSS, JavaScript frontend
  • Python and Django backend
  • CNN text classifier trained on a custom dataset
  • MySQL database
